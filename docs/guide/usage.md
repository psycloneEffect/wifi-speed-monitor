# 使い方ガイド

WiFi Speed Monitor の基本的な使い方を説明します。

## 🚀 起動方法

### コマンドラインから起動

```bash
# インストール済みの場合
wifi-speed-monitor

# ソースから実行する場合
python -m project.main
```

### Windows での起動

- スタートメニューから "WiFi Speed Monitor" を検索
- または、インストールフォルダから `WiFiSpeedMonitor.exe` を実行

### 自動起動の設定

**Windows:**

1. システムトレイのアイコンを右クリック
2. "設定" → "自動起動を有効にする"

または手動で：

1. `Win + R` で "shell:startup" を実行
2. WiFi Speed Monitor のショートカットを配置

## 📊 基本機能

### システムトレイアイコン

アプリケーションを起動すると、システムトレイ（タスクバーの右下）にアイコンが表示されます。

#### アイコンの色

- 🟢 **緑**: 接続品質が優良（Excellent）
- 🟡 **黄**: 接続品質が良好〜普通（Good/Fair）
- 🔴 **赤**: 接続品質が悪い（Poor）
- ⚪ **グレー**: 測定中またはオフライン

### ツールチップ表示

システムトレイアイコンにマウスカーソルを合わせると、現在のネットワーク情報が表示されます。

```
━━━━━━━━━━━━━━━━
📡 MyWiFi Network
⬇️ 95.3 Mbps
⬆️ 45.8 Mbps
⏱️ 28 ms
📊 Excellent
━━━━━━━━━━━━━━━━
安定性: 92%
ジッター: 3.2ms
```

#### 表示項目の説明

- **📡 ネットワーク名**: 接続中のWiFi SSID
- **⬇️ ダウンロード速度**: 受信速度（Mbps）
- **⬆️ アップロード速度**: 送信速度（Mbps）
- **⏱️ レイテンシ**: 応答時間（ms）、小さいほど良い
- **📊 接続品質**: Excellent / Good / Fair / Poor
- **安定性**: 接続の一貫性（0-100%）
- **ジッター**: レイテンシのばらつき（ms）

## 📈 詳細情報ウィンドウ

### 開き方

1. システムトレイアイコンをダブルクリック
2. または右クリック → "詳細を表示"

### 表示内容

#### 概要タブ

- 現在の速度とレイテンシ
- 接続品質の評価
- WiFi 信号強度
- 接続時間

#### 統計タブ

- 過去1時間の速度グラフ
- レイテンシの推移
- パケットロス率
- 最高/最低/平均値

#### 履歴タブ

- 過去の測定記録
- 日時別の統計
- データのエクスポート

## 🔧 設定

### 基本設定

#### 監視間隔

ネットワーク統計を取得する間隔を設定できます。

- **デフォルト**: 10秒
- **範囲**: 5秒 〜 60秒
- **推奨**: 10-15秒（バッテリー消費とのバランス）

#### 速度測定

定期的な速度測定（speedtest）の設定。

- **自動測定**: 有効/無効
- **測定間隔**: 15分 / 30分 / 1時間 / 手動のみ
- **注意**: 頻繁な測定はネットワーク帯域を消費します

#### 通知設定

特定の条件で通知を表示します。

- **接続品質低下時**: 品質が Poor になった時
- **速度低下時**: 速度が設定値以下になった時
- **レイテンシ上昇時**: レイテンシが設定値以上になった時

### 詳細設定

#### データ保存

- **履歴保存期間**: 7日 / 30日 / 90日
- **データベースサイズ**: 自動管理
- **エクスポート形式**: CSV / JSON

#### 外観

- **テーマ**: ライト / ダーク / システム
- **アイコンスタイル**: デフォルト / シンプル / カラフル
- **フォントサイズ**: 小 / 中 / 大

#### 高度な設定

- **測定サーバー**: 自動 / 手動選択
- **タイムアウト**: 5秒 / 10秒 / 15秒
- **ログレベル**: INFO / DEBUG

## 📊 速度測定

### 自動測定

設定で有効にすると、定期的に速度測定を実行します。

- バックグラウンドで実行
- 結果は履歴に保存
- 測定中は通常のモニタリングも継続

### 手動測定

いつでも手動で速度測定を実行できます。

1. システムトレイアイコンを右クリック
2. "手動で速度測定" を選択
3. 測定完了まで待つ（10-30秒）

**注意**: 測定中はネットワーク帯域を使用します。

## 📝 ログとトラブルシューティング

### ログの確認

ログファイルの場所：

```
Windows: %APPDATA%\SpeedFinder\logs\
macOS: ~/Library/Logs/SpeedFinder/
Linux: ~/.local/share/SpeedFinder/logs/
```

### よくある問題

#### 速度が正しく表示されない

**原因**: ネットワークアダプターの問題

**解決策**:

1. アプリを再起動
2. ネットワーク接続を確認
3. 管理者権限で実行（Windows）

#### システムトレイに表示されない

**原因**: タスクトレイの設定

**解決策** (Windows 11):

1. 設定 → 個人用設定 → タスクバー
2. "その他のシステムトレイアイコン"
3. "WiFi Speed Monitor" を有効化

#### 測定が遅い/失敗する

**原因**: ファイアウォールまたはネットワーク設定

**解決策**:

1. ファイアウォールの例外に追加
2. VPN を一時的に無効化
3. 測定サーバーを変更

## 💡 使い方のヒント

### バッテリー節約

ノートPCでの使用時：

- 監視間隔を長く設定（30-60秒）
- 自動速度測定を無効化
- 通知を最小限に

### 詳細な分析

ネットワーク品質を詳しく確認：

- 詳細情報ウィンドウを常時表示
- 履歴データをCSVでエクスポート
- 複数の時間帯で測定

### リモートワーク

在宅勤務での利用：

- レイテンシ通知を有効化
- ビデオ会議前に手動測定
- 定期的な速度チェック

## 🎯 ユースケース

### ケース1: 在宅ワーク

**目的**: 安定したネットワーク環境の確保

**設定**:

- 監視間隔: 10秒
- レイテンシ通知: 100ms以上で通知
- 速度測定: 30分ごと

### ケース2: オンラインゲーム

**目的**: 低レイテンシの維持

**設定**:

- 監視間隔: 5秒
- レイテンシ通知: 50ms以上で通知
- 詳細ウィンドウを常時表示

### ケース3: ストリーミング

**目的**: 安定した帯域の確保

**設定**:

- 監視間隔: 15秒
- 速度通知: 10Mbps以下で通知
- 自動速度測定: 1時間ごと
