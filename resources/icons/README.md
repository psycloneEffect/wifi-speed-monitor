# アイコンリソース

このディレクトリには、Speed Finderのシステムトレイアイコンが格納されています。

## 必要なアイコンファイル

以下の5種類のアイコンが必要です：

- `excellent.png` - 優れた接続品質（緑色）
- `good.png` - 良好な接続品質（青色）
- `fair.png` - 普通の接続品質（黄色）
- `poor.png` - 悪い接続品質（赤色）
- `unknown.png` - 不明な接続品質（灰色）

## アイコン仕様

- **サイズ**: 16x16px, 32x32px, 48x48px（マルチサイズ推奨）
- **フォーマット**: PNG（透過背景）
- **色**: 接続品質に応じた直感的な色使い

## 生成方法

現在、シンプルなプレースホルダーアイコンを使用しています。
本番環境では、以下のツールを使用してプロフェッショナルなアイコンを作成することを推奨します：

- **Figma**: デザインツール
- **Inkscape**: ベクターグラフィックエディタ
- **GIMP**: ラスターグラフィックエディタ
- **IconScout**: アイコンライブラリ
